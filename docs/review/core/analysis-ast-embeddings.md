Clean: masking.ts (length-preserving, overlap-safe, no shared-lastIndex trap), source-analysis.ts routing/SFC-degradation contract, sfcScriptFilename.

## Strengths
- Masking design keeps line numbers exact across Vue/Svelte script blocks and templates; broken SFCs degrade to template-selectors-only instead of being dropped — spec-verified.
- Selector hygiene: literal values only, interpolation rejected across 6 dialects, dynamic-binding names skipped, shared cap/dedupe/priority finalizer — "never hand the model a fabricated selector" is consistently enforced.
- EmbeddingsGenerator: in-flight dedupe, LRU with refresh-on-hit, batch failure isolation (allSettled with index-aligned nulls).
- Local deterministic embeddings (mean pooling + normalize, quantized MiniLM) — reproducible vectors, no network.
- Parser error contract (file:line, sanitized filename) makes warn-and-continue informative.

## Test-coverage observations
- ast-parser.spec.ts:254-261 asserts toBeGreaterThanOrEqual(0) for `export * from` — a VACUOUS assertion documenting the missing behavior instead of testing it.
- Decorators tested only before-export; `export @Component class` (throws), accessor, using untested.
- No default-parameter test (the "param" corruption invisible); no angle-bracket-assertion test; no inline import-type test; no ClassExpression/string-key test.
- entry-points.ts has NO spec at all (App Router globbing, framework switch/dead nuxt case, dedup priority, workspace recursion).
- symbol-extractor.ts has no direct spec — calls/renders resolution, (group)/[param] routes, express matching only indirectly exercised.
- embeddings.spec.ts almost entirely model-dependent skips; truncation, surrogate, LRU-eviction untested.

## Verdict
**needs fixes** — the import layer silently drops all re-export/CJS dependency edges, default-parameter signatures are corrupted to "param", and several legal TS syntaxes (decorator-after-export, angle-bracket assertions, Vue generic scripts) throw and blank whole files, so the graph and embeddings this product stands on are wrong or missing for very common real-world code.
